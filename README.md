# color-prediction — AuraWin

Production web-app conversion of the **AuraWin** Wingo-style color-prediction prototype.

- **Phase 1:** frontend-only (Next.js App Router + TypeScript + Tailwind v4 + Zustand), state in
  localStorage behind a repository seam. Pixel-perfect to the prototype; fully responsive.
- Planning, architecture, ADRs, and the live execution tracker live on the feature branches
  (`docs/`, `process.md`).

> Simulated demo — no real money. 18+.
